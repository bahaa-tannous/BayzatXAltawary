# موقع الطوارئ العربية × بيزات

## النشر على GitHub Pages (باستخدام GitHub Desktop)
1. افتح GitHub Desktop وسجّل الدخول بحساب bahaa-tannous.
2. File ثم Add local repository، واختر هذا المجلد. إذا طلب إنشاء مستودع اختر Create a repository.
3. اسم المستودع المقترح: bz-9k2m-demo (اسم غير واضح عمدًا).
4. اضغط Commit to main ثم Publish repository.
5. على github.com افتح المستودع: Settings ثم Pages، وفي Source اختر Deploy from a branch، الفرع main والمجلد / (root)، ثم Save.
6. بعد دقيقة أو دقيقتين يظهر الرابط في نفس الصفحة.

## ملاحظات
- الصفحة عامة لكل من يملك الرابط (لا يوجد تحكم وصول في GitHub Pages المجاني)، وفيها وسم noindex وملف robots.txt لمنع الفهرسة.
- لإضافة رابط زر «رتّب معنا زيارة الفريق»: افتح index.html وغيّر قيمة CONTACT_URL داخل السكربت (مثال: رابط واتساب).
- جميع الأرقام والأسماء في الصفحة توضيحية.
